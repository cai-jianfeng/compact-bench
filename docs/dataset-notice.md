# Upstream material

Compact-Bench includes task material derived from
[SWE-bench](https://github.com/SWE-bench/SWE-bench) and working-directory
snapshots from these public repositories:

- [Flask](https://github.com/pallets/flask)
- [Requests](https://github.com/psf/requests)
- [xarray](https://github.com/pydata/xarray)
- [Pylint](https://github.com/pylint-dev/pylint)
- [pytest](https://github.com/pytest-dev/pytest)
- [Sphinx](https://github.com/sphinx-doc/sphinx)
- [SymPy](https://github.com/sympy/sympy)

The exact repository and base commit are recorded for each task in
`e1/instances.json`. Snapshots include their upstream license and copyright
notices. They are working copies containing the benchmark's applied test patch
and the frozen agent changes, rather than pristine upstream source releases.
Compact-Bench's Apache-2.0 license does not replace upstream license terms.

Issue statements, third-party code quoted in sessions, and other upstream
material remain subject to their respective terms.
